# Design Ideas

### Concept 1 — "Garden Estate" (best fit for Milton Park)
- **Palette:** sage green, warm ivory, soft terracotta, and a touch of muted gold
- **Type:** an elegant serif for headings (e.g. Cormorant Garamond or Playfair Display) paired with a clean sans for body text (e.g. Montserrat or Inter)
- **Graphics:** hand-drawn botanical line illustrations — tulips (nod to the Tulip Lawn) and weeping beech leaves framing each section
- **Feel:** like a heritage country house invitation brought online

### Concept 2 — "Highlands Modern"
- **Palette:** deep forest green, cream, and charcoal
- **Type:** high-contrast serif headlines, generous white space, minimal decoration
- **Hero:** full-bleed engagement photo with the names overlaid in large type
- **Feel:** editorial and understated, like a magazine spread

### Concept 3 — "Spring Romance"
- **Palette:** blush, dusty blue, sage, ivory
- **Type:** script for names only (e.g. Pinyon Script), serif everywhere else
- **Graphics:** watercolour florals, soft paper texture backgrounds
- **Feel:** soft, warm and classic

### Cool features to add
- **Monogram:** an "K & N" crest with a tulip motif — reuse it on invitations, signage, napkins and the site favicon
- **Live countdown** on the home page
- **Illustrated venue map** — a hand-drawn map of the estate showing Tulip Lawn → Gardens → Ballroom, with little icons for each part of the day
- **Interactive timeline** that animates as guests scroll down the schedule
- **Dress code mood board** — a row of colour swatches and outfit inspiration images so guests aren't guessing
- **Spotify playlist embed** built from RSVP song requests
- **"Add to calendar" button** (Google / Apple / Outlook) with the venue address pre-filled
- **QR code** on printed invitations linking straight to the RSVP page
- **Weather widget** that goes live in the final week
- **Guest photo upload** page (or QR codes on tables on the night)
- **Password-protect** the site so only invited guests see the details
- **Save-the-date reveal animation** — an envelope that opens on first visit to show the date
